# البوابة الأكاديمية الشخصية

موقع أكاديمي شخصي باستخدام Quarto + GitHub Pages + Pages CMS

## الهيكل

- `index.qmd` — الصفحة الرئيسية
- `about.qmd` — السيرة العلمية
- `publications.qmd` — المنشورات
- `teaching.qmd` — التدريس
- `research.qmd` — الأبحاث
- `contact.qmd` — التواصل
- `styles.css` — التنسيقات
- `.pages.yml` — إعدادات Pages CMS

## التعديل عبر المتصفح

1. ادخل إلى [app.pagescms.org](https://app.pagescms.org)
2. سجّل الدخول بحساب GitHub
3. اختر هذا المستودع
4. عدّل النصوص وارفع الملفات مباشرة

## النشر التلقائي

عند كل حفظ، يُبنى الموقع تلقائيًا عبر GitHub Actions ويُنشر على:
`https://yourname.github.io`
